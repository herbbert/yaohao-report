## 阶梯规则

每 12 次摇号升一阶，倍率递增；72 次以上可直接领牌。

| 阶梯 | 次数 | 倍率 |
|------|------|------|
| 1 | 1-12 | 1x |
| 2 | 13-24 | 2x |
| 3 | 25-36 | 3x |
| 4 | 37-48 | 4x |
| 5 | 49-60 | 5x |
| 6 | 61-72 | 6x |
| 领牌 | 73+ | 直领 |
